In fairness — what is open on our side

Strong, not spotless

The design side is strong, not spotless. These are the open items on our side of the line — all of them small, specific and already understood.

  • Residual unbound fillsFill binding is at 96%, or 98.6% once icon placeholders are excluded. What remains is the logo brand marks and placeholder text still sitting in accordion-item.
  • 66 of 128 components undescribedHalf the in-scope set has no description. The 62 that do average 1,342 characters — when this team documents, it documents properly.
  • Properties Glossary has drifted14 of 34 entries are spelled differently from the real Figma property, and 8 match none. Now a generatable diff rather than a manual audit.
  • UI Kit changelog stalledLast real entry is 0.0.20 on 8 May, with a malformed [0.0.0] entry above it.
  • Semver documented, not practised0.0.15 deprecated three components and renamed two — and shipped as a patch.
  • One open contrast reportBrand-on-dark AA failure on free and secondary buttons, unanswered since 31 July.
  • 2 broken variable aliasesdimension/size/icon/default points at deleted variables in both Smart Strength modes, so icon sizing falls back on that hardware. Specific and quick to repoint.
  • 35 undescribed variablesAll recent component-level additions. The other 1,584 are described — 98% coverage.
  • 1 broken component setillustrative-empty-state has conflicting variant combinations, so Figma cannot read its properties at all.
  • One icon breaks hyphen-case"genius weekly target" uses spaces where all 347 others use hyphens.
  • 3 public properties still disagreeIntent on two date components, isLoading on card-class, and is user filled on input-text and input-unit. Renaming these is breaking, so it needs the scheduled track and a migration note rather than a quiet fix.

Why this stays red

The gap is concentrated on the single most-used control in any system

The yellow anchor requires the core set to be “mostly present”. A system whose consumers write 36 raw <input> elements across five repositories does not have its core set present. input-text, input-dropdown, textarea and toggle all have full Figma property contracts and no code.

The slot is not empty — it is occupied by a mature, documented, react-hook-form-compatible library. A minimal component will become the fifth option in those applications rather than replacing anything.

The only two pairs below 4.5:1 are disabled text at 2.1:1. WCAG 1.4.3 explicitly exempts inactive controls from the contrast minimum, so every pair that the guideline actually governs passes.

One caveat, stated plainly. The EGYM accent pairs land on exactly 4.5:1 — passing, but with no headroom. Any darkening of the surface or lightening of the accent breaks them.

The gate that produced those numbers

Accessibility is a required phase, not a review note

WCAG 2.2 AA is a mandatory phase in the contribution checklist: ARIA Authoring Practices, keyboard paths, contrast ratios, 44x44 touch targets, reduced motion and screen-reader testing.

Already moving on the code side. delegatesFocus is now the house pattern, the tooltip enforces focusable anchors, and PR #166 adds the first behavioural focus-ring test — approved and still unmerged.

In fairness

One item is ours

One reported brand-on-dark AA contrast failure on free and secondary buttons, unanswered since 31 July. Dark mode is scaffolding — 7 variables against 1,111 in Brand — so this sits outside the shipped surface.

Of the components that model interaction states at all, 94% include a focus state. Most of those without a state property are containers — cards, navigation shells, button stacks — where the interaction lives in the child.

Station 02 · best practices

One component is the whole problem

Of 35 component stylesheets, 34 are .scss and exactly one is .css. Of 15 components, 14 use reflected properties — eo-link uses none, and renders no anchor element at all.

Figma craft is the counterweight, and it is now measured across the full population rather than sampled: 0.54% generic layer names across all 109,402 layers, zero detached instances, 96% of fills and 100% of strokes bound, and zero local styles left anywhere. The conventions exist. Nothing enforces them in code.

Station 05 · testing

Two characters, and a branch protection setting

vitest.config.ts points at two paths that do not exist — vitest.config.storybook/ts and packages/eguym-…. The 6-point gap

Finished work nobody can reach

Stations 06, 09 and 10 are held down almost entirely by an AI-readiness repository sitting in a playground organisation that is not linked from either design system repo, from Notion, or from Slack. It holds a validated 3,061-token design.md, 127 machine-readable component contracts against a published JSON Schema, a working design-to-token drift detector, and an agent skill wired for both Claude Code and Copilot. Both of its validators pass, offline, in under a second.

Promoting it is a move, not a build. It is the largest single score movement available.
